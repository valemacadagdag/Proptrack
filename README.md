PropTrack is a web-based property management system designed to streamline property listings and user management. This project was developed using the CodeIgniter 4 framework, adhering to the Model-View-Controller (MVC) architectural pattern.

Features
   Security: Implemented CSRF tokens and XSS protection to secure user data and prevent unauthorized requests.

   User Management: Includes secure registration and login functionality.

   Data Handling: Supports file uploads, automated email notifications, and paginated search capabilities for efficient data management.

   Testing: Includes a PHPUnit test suite with more than three passing tests to ensure system reliability.


Installation Steps
   Clone this repository to your local machine.

  Run composer install to download the required dependencies.

  Import the provided SQL dump file into your local database.

  Configure your .env file to match your database settings.

  Serve the application using php spark serve.


Deployment
The application is fully deployed and accessible via a live URL, ensuring it meets all project submission requirements.
